# DECISIONS

## From Minh
- Build host: mac-work-2 (toolchain present, real screen for tests). No sudo, no extra macOS permissions for core features.
- Name "Ergonomic Video Player", CLI `evp <path>`, `./install.sh` sets up everything. Lives as folder `evp/` in `MT-GoCode/minh-qol-utilities` with that repo's per-tool conventions (`install.sh`, `uninstall.sh`, `README.md`, shared `signing-ladder.sh`). Work happens on branch `evp`.
- Transcript support dropped.
- No always-on-top.
- Speed and volume are per video file, not global.
- Screenshot: clipboard only, no Shift variant.
- Double-click on the time field selects it all; typing/Delete replaces; Enter seeks if valid.
- Audio-track and subtitle-track menus: yes.
- Extremely minimal, no bloat, no reinvented wheels. No reviews during this planning pass.

## From me (accepted by silence on "go"; revisit if Minh objects)
- Engine: libmpv from Homebrew (`brew install mpv`), linked dynamically from `/opt/homebrew/lib`. Not bundled (supersedes my earlier "bundled dylibs" claim: bundling 21 transitive dependencies is bloat and ffmpeg updates would diverge from the bundle).
- UI toolkit: AppKit, SwiftPM executable, assembled into `EVP.app` by script, ad-hoc signed.
- Own Open Recent menu built from the state store (system menu cannot show timestamps).
- Media-key mapping when coupled: F8 play/pause, F7 back by the J step, F9 forward by the J step.
- Global state: one JSON file in `~/Library/Application Support/EVP/`. One writer (the app); CLI never touches it.
- CLI delivers to the running app through a registered `evp://` URL via `open`, so there is one instance and one state writer.
- New file defaults: 1.0x speed, 100% volume.
- `Tab` toggles bar visibility per window; stored per window in session state.

## Discoveries (probes, 2026-10-30, mac-work-2)
- libmpv `wid` embedding draws nothing on macOS; the render API with `NSOpenGLView` works (needs render context before `loadfile`).
- Ctrl+Space via Carbon hotkey works with no permission.
- Media keys via `MPRemoteCommandCenter`: F7/F9 route to EVP; F8 routes only when no other app (Chrome) holds a media session. Gate G1 discharged, see STRATA.md.
- `brew install mpv` upgraded existing brew deps on this machine as a side effect.

- State durability (2026-10-30, review L13): `state.json` is written with an atomic rename and no fsync. A killed process always leaves a complete file (tested with kill -9). A power cut or kernel panic can lose the last second of positions, and may leave an empty file, which the app refuses and does not overwrite. I chose not to fsync because `flushNow` runs on the main thread and a full sync costs tens of milliseconds there; the README says the limit. Revisit if Minh wants power-cut safety.
