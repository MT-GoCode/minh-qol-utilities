## Architecture (fixed up front so every stratum extends it)

SwiftPM package `EVP`; targets and tests:

- `CMpv`: system-library module found through `pkg-config` (headers `client.h`, `render.h`, `render_gl.h`). Verified in P3.
- `EVPCore` (library, **no AppKit**): `MpvPlayer`, `Action`, `KeyChord`, `Keymap`, `Settings`, `TimeFormat`, `StateStore`, `ResumePolicy`. Everything testable headless.
- `EVPStateStress` (executable, test-only): the writer the kill -9 durability test starts and kills. The app build uses `swift build --product EVP`, so it never ships.
- `EVP` (executable, from stratum 4): AppKit only. `AppDelegate`, `PlayerWindowController`, `GLVideoView`, `ControlBar` views, menus, `SettingsWindowController`, `MediaKeys`, `GlobalHotkey`.
- `Tests/`: **one** XCTest target, one command `./test [--filter X]`, hierarchical classes `Unit*`, `Integration*`, `E2E*`, results in `results/<timestamp>-<pid>/` (xunit plus per-check log).

Core abstractions (strata 1 to 3 built, then only extended):
- `Action` (enum, built): the closed set of **bindable** operations (`playPause`, `seekBackShort`, `seekForwardLong`, `speedUp`, `speedReset`, `jump0` to `jump9`, `frameBack`, `mute`, `fullscreen`, `screenshot`, `toggleBar`, `pauseAll`, ...), the row list of the Keybinds tab and the key of `Keymap`.
- `Command` (enum, stratum 5, first consumer): what the window controller executes: `.action(Action)` plus the payload operations no key can name (`.seek(TimeInput)` from the time field, `.seekFraction(Double)` from the scrub bar, `.setVolume(Double)` from the slider, `.select(Track.Kind, id:)` from the track menus). **Keys, menu items, bar buttons, sliders and media keys all call the one `perform(_ command: Command)` on the window controller.** No second path to any behaviour.
- `Keymap` (built): `[Action: KeyChord]`, tolerant versioned Codable (null means unbound, missing means default), conflict detection.
- `MpvPlayer` (built): the only code that touches libmpv. Properties are observed, never polled.
- `StateStore` (built): single writer of `~/Library/Application Support/EVP/state.json` (override with env `EVP_HOME` for tests). Versioned, tolerant of missing fields, refuses newer files. Per-file `{position, speed, volume}`, windows `[{id, path, frame, barHidden}]`, recents, settings.

Constants and their origin:
- Seek 5 s / 10 s, speed step 10%: Minh.
- Autosave at most 1 s behind playback: Minh's "constantly"; my decision for the number.
- Reopen at 0 within 5 s of the end: my proposal, accepted.
- Speed step is additive 0.1x. Volume 0 to 100 in steps of 5. Both my decisions (DECISIONS.md).

Test fixtures: `Tools/make-fixtures` (ffmpeg) generates the five formats; tests never use real user files.

Review schedule (Minh's call): fresh Sonnet code reviews run only at period ends, after strata **3, 8, 10 and 14**, each over the whole codebase built so far, in rounds until no HIGH or MEDIUM. Strata in between are gated by their own green tests and by mutation checks of the tests that claim to catch something. Stratum 1's open round-3 findings are fixed in code and covered by the stratum 3 review.

No sub-journeys: every stratum extends the shared `Action`/`Keymap`/`StateStore` types, so fan-out would cost more coordination than the small strata save.

## STRATUM 12: Media-key decoupling and global pause  [BUILT]
description: `MediaKeys` registers `MPRemoteCommandCenter` commands (togglePlayPause/play/pause; previousTrack and nextTrack, which are F7 and F9, map to back and forward by the J/L step) and publishes now-playing state **only while a window is playing and `decoupleMediaKeys` is false**.
